📖 Acerca de Delantal Digital

Cocina con tecnología - Un proyecto de portafolio

¿Qué es Delantal Digital?

Es una web app responsive que permite buscar recetas, ver sus detalles y guardarlas como favoritas usando almacenamiento local.

Tecnologías utilizadas

  • ✅ HTML5 Semántico
  • ✅ CSS3 (Flexbox, Grid, Variables)
  • ✅ JavaScript ES6+ (Fetch API, Async/Await)
  • ✅ LocalStorage para favoritos
  • ✅ TheMealDB API

Características

  • 🔍 Búsqueda de recetas por nombre
  • ❤️ Sistema de favoritos persistente
  • 📱 Diseño 100% responsive
  • 🌙 Modo oscuro/claro
  • ♿ Accesibilidad básica
